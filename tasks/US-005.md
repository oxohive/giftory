# US-005: Begin Phase 2 — Dealer Marketplace Foundation

- **Parent Feature:** Planned — FEAT-008 (Dealer Marketplace, not yet documented)
- **Status:** Proposed
- **Priority:** Medium
- **Evidence / Origin:** `docs/architecture.md` §19 — Phase 2 stack; `docs/architecture.md` §7 — Dealer Marketplace & Orchestration.

## User Story

As the platform operator,  
I want dealers to be able to onboard and receive order assignments,  
so that customized gifts can be fulfilled by qualified producers.

## Context

Phase 1 established the commerce foundation. Phase 2 introduces the dealer marketplace — the mechanism by which orders for customizable products get routed to dealers who can produce them. According to `docs/architecture.md`, Phase 2 introduces: dealer portal, dealer modules, commission engine, payout foundation, and KYC.

This story is **Proposed** — it requires scoping and breaking down before implementation begins. It is recorded here to mark the next phase boundary.

## Acceptance Criteria (High-Level — to be refined)

1. A dealer can register and complete KYC onboarding.
2. An admin can approve a dealer and configure their capabilities (product types, printing methods, capacity).
3. An order for a customizable product can be assigned to a dealer (manually, Phase 2 MVP).
4. The assigned dealer can see the order and its production requirements.
5. Commission is calculated and recorded per order line.

## Scope

- **Included (Phase 2 MVP):** Dealer onboarding, manual assignment by admin, commission snapshot per order, dealer portal foundation.
- **Excluded:** Automated matching (Phase 5), RFQ/quotation (Phase 5), split payouts (to be decided — see architecture.md §20 open decision #2).

## Dependencies

- Open Mercato `directory` module — dealers as organizations
- Architecture decision #2: Payment provider for split payouts (Stripe Connect vs Razorpay Route)
- [US-002](US-002.md) — Phase 1 test checklist must be complete before Phase 2 begins.
- Phase 1 must be production-ready (checklist, gap G7 fix, demo product cleanup).
